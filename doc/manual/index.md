## Ask a question 

Feel free to email me: `hi@eltr.ac`. Ask me anything you are not sure about. Opening an issue to ask questions is also OK, but I might be slow to respond.

## Report a bug 

I don't care for issue templates. When [submitting a new issue](https://codeberg.org/eltrac/weepinbell/issues/new), all you need to do is try to get these information as clear as possible.

1. Versions 
    - Weepinbell version 
    - JDK version 
    - Operating system version
    - Browser version (if relevant)
2. Your configuration file (hide your secrets and keys)
3. What you did (How can we reproduce this bug?)
4. Logs
    - `docker logs` or `journalctl` or whatever you're using
